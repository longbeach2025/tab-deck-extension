Tab Deck 功能说明与使用方法

项目地址：https://github.com/longbeach2025/tab-deck-extension

Tab Deck 是什么

Tab Deck 是一个 Chrome 标签页管理插件，用来替代 Toby 这类工具。它会把 Chrome 新标签页变成一个“标签工作台”，你可以把当前打开的网页保存成集合，在多设备之间同步，再按项目、主题或工作场景恢复。

核心功能

1. 新标签页工作台

安装后，Chrome 的新标签页会变成 Tab Deck 主界面。

左侧包括：

  • 搜索框
  • Spaces 空间列表
  • 当前窗口打开的标签页
  • 保存选中标签页
  • 保存全部标签页
  • 保存后关闭原标签页选项

右侧包括：

  • 当前 Space 的所有 Collections
  • 每个 Collection 里的已保存链接
  • Collection 笔记
  • 手动添加链接
  • 一键打开整个 Collection

2. Space 空间

Space 是最高层级分类，可以理解为“大工作区”。例如：

  • Work
  • Trading
  • Research
  • Personal
  • Client A
  • Client B

每个 Space 下面可以有多个 Collection。当前支持新建、切换、重命名和删除 Space。

3. Collection 集合

Collection 是一组标签页或链接，可以理解为“一次工作会话”或“一个主题文件夹”。例如：

  • 2026 Budget Review
  • AI Research
  • Chrome Extension Dev
  • Morning Reading
  • Supplier Docs

每个 Collection 支持保存多个标签页、添加笔记、手动添加链接、删除单个链接、删除整个 Collection，以及一键打开全部链接。

4. 保存当前标签页

点击浏览器右上角的 Tab Deck 插件图标，会打开 popup。在 popup 里可以：

  • 选择 Space
  • 选择已有 Collection
  • 或输入一个新 Collection 名称
  • 保存当前标签页
  • 保存当前窗口所有标签页
  • 选择保存后是否关闭原标签页

这个入口适合快速整理当前浏览状态。

5. 保存当前窗口

在主工作台左侧，可以看到当前窗口所有可保存的标签页。你可以：

  • 勾选部分标签页，然后点击 Save selected
  • 直接点击 Save all
  • 勾选 Close after save，保存后自动关闭这些标签页

这适合把一堆打开的网页收纳起来，清空浏览器窗口。

6. 拖拽保存

主界面左侧的当前标签页可以直接拖到右侧某个 Collection 里。这个方式适合你边整理边归类，不用每次弹窗输入。

7. 搜索

顶部搜索框可以搜索：

  • 链接标题
  • URL
  • 域名
  • Collection 名称
  • Collection 笔记

保存很多链接后，可以用搜索快速找回。

8. 多设备同步

当前版本已经支持 Chrome 账号同步。

  • 默认保存到 chrome.storage.sync
  • 多台设备登录同一个 Chrome 账号后自动同步
  • 同时保留一份 chrome.storage.local 本地副本
  • 如果同步失败或数据超过限制，会退回本地保存，并显示 Local fallback
注意：Chrome sync 适合个人多设备轻量使用，不适合无限量存储。大概几百个链接以内比较合适。

安装方法

  1. 打开 GitHub 仓库：https://github.com/longbeach2025/tab-deck-extension
  2. 克隆或下载代码到本地。
  3. 打开 Chrome：chrome://extensions
  4. 打开右上角 Developer mode。
  5. 点击 Load unpacked。
  6. 选择本地目录：/Users/reclina/tab-deck-extension
  7. 安装后打开一个新标签页，就会进入 Tab Deck 主界面。

推荐使用方式

可以按这个结构管理：

Space: Work
  Collection: Finance Budget
  Collection: Chrome Extension Dev
  Collection: Vendor Research

Space: Personal
  Collection: Reading List
  Collection: Travel
  Collection: Shopping

Space: Trading
  Collection: Market Dashboards
  Collection: Research Reports

日常流程：

  1. 工作时先正常打开网页。
  2. 准备切换任务时，打开 Tab Deck。
  3. 选择当前窗口的标签页。
  4. 保存到某个 Collection。
  5. 勾选 Close after save 清空窗口。
  6. 下次继续时，找到 Collection，点击打开全部链接。
